# Sharpen the task

Before starting, consider how an expert would approach the task, which raw sources they would use, how they would check the result, what the user is really after, and whether the task is over- or underspecified. Loosen constraints that do not serve the goal as readily as you add useful ones. Leave product choices that belong to the user open. Fold in only what improves the work without enlarging its scope. Keep a concrete check against the real result, then do the authorized work without narrating the framing.

Follow the [Pi execution contract](../poteto-mode/references/pi-runtime.md). This invocation does not add permission to delegate, publish, message others or start a goal.
